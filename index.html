웹 데모 안내 · 1

설치 없이, 브라우저에서 바로 돌아갑니다

  • 링크만 열면 시작 설치도 가입도 없습니다. 데스크톱과 모바일 브라우저 모두에서 열리고, 화면은 실제 앱과 같은 모바일 비율로 표시됩니다.
  • 화면 안내를 따라가세요 화면 옆, 좁은 화면에서는 아래의 목록에 화면마다 무엇을 하는 곳인지 적어 두었습니다. 줄을 누르면 그 화면으로 바로 이동합니다.
  • 입력한 내용은 이 브라우저에만 브리핑 카드와 진료 기록은 브라우저 로컬스토리지에 저장됩니다. 새로고침해도 이어지고, 다른 기기로는 넘어가지 않습니다.
  • 처음부터 다시 보려면 시크릿 창으로 열거나 이 사이트의 저장 데이터를 지우면 초기 상태로 돌아갑니다. 몇 번이든 반복해서 보실 수 있습니다.

웹 데모 안내 · 2

앱에서 웹앱으로 옮기며 뺀 네 가지

  • 음성 입력(STT) 제외 앱에서는 AI 증상 문답과 진료 후 메모를 말로 입력합니다. 웹 데모에서는 같은 자리에서 키보드로 적습니다. 질문 순서와 카드에 실리는 내용은 같습니다.
  • 카카오 로그인 제외 앱에서는 카카오 계정으로 시작하고 기록이 계정에 묶입니다. 웹 데모의 로그인 화면은 흐름 확인용이라, 누르면 계정 연결 없이 다음으로 넘어갑니다.
  • 기기 설정 제어 불가 앱은 진료실에서 폰을 건넬 때 화면 밝기를 최대로 올립니다. 브라우저는 기기 설정을 바꿀 수 없어, 카드를 보여줄 때 밝기는 직접 올려 주세요.
  • 서버 연동 없이 로컬 저장 앱은 서버에 저장하고 기기 사이를 동기화합니다. 웹 데모는 이 브라우저의 로컬스토리지에만 저장합니다.

AI가 진단하지 않는다는 것, 환자가 확인하고 고치는 브리핑 카드, 모든 질문의 “잘 모르겠어요 · 없어요” 경로는 그대로입니다.
